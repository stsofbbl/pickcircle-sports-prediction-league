# YOSO 夏の甲子園2026 正式ルール

このファイルを夏の甲子園2026プリセットの参照元にする。
実装で迷った場合は、チャット履歴ではなくこのファイルを優先して確認する。

## 基本方針

- リアルマネー、決済、送金、換金、賭け機能は実装しない
- 外部オッズはゲーム内の強さ評価・倍率としてのみ使う
- 代表校は49校
- 1回戦スタート校は34校
- 2回戦スタート校は15校

## オッズ

```text
sqrt_odds = sqrt(外部オッズ)
sqrt_odds_capped = min(sqrt_odds, 50)
```

√オッズ上限は50倍。

## フェーズ1: 大会前・長期保有予想

- 各プレイヤーは49校から8校を指名する
- 予想かぶりはあり
- 2回戦スタート校は最大3校まで
- 1回戦スタート校は最低5校
- 8校の中からキャプテン校を1校選ぶ

フェーズ1得点:

```text
フェーズ1得点 =
フェーズ1到達ポイント
× sqrt_odds_capped
× キャプテン倍率
```

キャプテン倍率:

```text
通常校: 1.0倍
キャプテン校: 1.2倍
```

正式到達ポイント:

```text
initial_loss: 0
first_win_then_loss: 1
best16: 1.5
best8: 2
best4: 2.5
runner_up: 3.5
champion: 5
```

## リベンジカード

- ベスト16時点でフェーズ1指名校8校がすべて敗退しているプレイヤーのみ使用可能
- 原則、自分のフェーズ1指名校を直接倒した高校のうち、ベスト16に残っている高校から1校を選ぶ
- 該当校がいない場合は、ベスト16に残っている高校から任意の1校を選べる
- キャプテン倍率は適用しない

リベンジ得点:

```text
best16: 0
best8: 2 × sqrt_odds_capped
best4: 2.5 × sqrt_odds_capped
runner_up: 3.5 × sqrt_odds_capped
champion: 5 × sqrt_odds_capped
```

## フェーズ2: ベスト16ドラフト

- ベスト16が出揃った時点で16校を4人でドラフトする
- 1人4校
- かぶりなし
- フェーズ1指名校との重複保有は可能
- ドラフト順はフェーズ1暫定順位の下位からスネークドラフト

フェーズ2得点:

```text
best16: 0
best8: 20
best4: 40
runner_up: 60
champion: 100
```

## ゾンビモード

- ON/OFF可能なルールとして扱う
- ベスト4時点で、フェーズ2保有校4校がすべて敗退しているプレイヤーのみ発動
- 他プレイヤーが保有しているベスト4進出校のうち、準決勝で負けると思う高校を1校選ぶ
- ゾンビ本人への加点はない

ペナルティ:

```text
ゾンビ指定なし: 所有者は40点
ゾンビ1人が指定して的中: 所有者は20点
ゾンビ複数人が同じ高校を指定して的中: 所有者は0点
```

## フェーズ3: 決勝スコア予想

- 決勝カード確定後、決勝開始前までにスコアを予想する
- 同点予想は不可
- 勝者のみ的中ポイントは設けない

得点:

```text
完全スコア的中: 50点
完全的中者なしの場合、最も近い人: 30点
勝者のみ的中: 0点
```
