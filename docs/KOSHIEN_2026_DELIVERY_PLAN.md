# 夏の甲子園リリース計画

最終更新: 2026-06-24

## 目標

夏の甲子園までに、仲間内で実際に使えるYOSOアプリにする。

W杯2026のUIはプロトタイプとして残し、当面は深追いしない。開発の主戦場を以下へ移す。

- Google Sheets連携
- 実際に友達が同じ大会データを共有できるWebアプリ化
- 夏の甲子園向けプリセット
- スマホで迷わず使える予想、結果入力、ランキング

## 前提日程

2026-06-24時点の公開情報をもとに、夏の甲子園は以下を前提に逆算する。

- 2026-08-01: 3回戦以前の組み合わせ抽選予定
- 2026-08-05: 第108回全国高等学校野球選手権大会 開幕予定
- 2026-08-22: 決勝予定

天候や運営都合で日程変更の可能性があるため、アプリ側では大会日程を管理者が変更できる前提にする。

## リリース判定

8月5日の開幕前に、以下ができていれば実用開始とする。

- 友達が公開URLからアクセスできる
- 同じリーグデータをGoogle Sheets経由で共有できる
- 管理者が大会、参加者、締切、結果を管理できる
- 参加者が自分のYOSOだけ入力できる
- 締切後に全員のYOSOを見られる
- 結果確定後にランキングへ反映される
- スマホで主要操作が破綻しない

## 今回やらないこと

- W杯2026 UIの完成
- メール認証
- パスワードリセットメール
- 決済、送金、リアルマネー要素
- App Store申請
- 複雑な権限管理
- 大規模ユーザー向けのDB最適化

## 週次スケジュール

### 6/24 - 6/30: オンライン同期MVPの土台

目的: 端末内保存から、Google Sheets共有へ移る。

P0:

- Apps Script APIを作る
- Google Sheetsに `state`, `audit_log`, `members` タブを作る
- `getState` / `saveState` を実装
- フロント側に同期ボタンを追加
- 設定画面のApps Script URL / Spreadsheet IDから同期できるようにする
- 失敗時にローカル保存へ戻れるようにする

P1:

- 同期中、同期成功、同期失敗の表示
- 最終同期時刻の更新
- 保存前の簡易バックアップ

完了条件:

- PCとスマホの別ブラウザで同じリーグ状態を共有できる

### 7/1 - 7/7: 甲子園プリセット設計と基本実装

目的: 夏の甲子園用の予想形式を固める。

P0:

- `koshien` プリセットを追加
- 49代表校を管理者が入力、貼り付け、編集できる
- 予想形式を決める

  - 準優勝
  - ベスト4
  - ベスト8
  - 注目校またはダークホース
- 締切前は自分のYOSOだけ表示
- 締切後は全員のYOSO公開

P1:

- 代表校リストのCSV貼り付け
- 都道府県ラベル
- 予想入力の進捗表示

完了条件:

- 仮の49校で、参加者が甲子園YOSOを入力できる

### 7/8 - 7/14: 結果入力とランキング実用化
